# Data-Driven-Soft-Sensor-for-a-Crystallizer-PLS-and-Gaussian-Process-Regression
A data-driven soft sensor predicts L50 from nine sensors using PLS and GPR, with six-stage preprocessing (KNN imputation, IQR outliers, drift, duplicates), 5-fold CV, and a leakage-free 3-way split. GPR gives R² = 0.996, RMSE = 1.16 µm, 89.97% coverage, using numpy, pandas, matplotlib, sklearn.
